A PDF looks like a finished page, but inside it's a structured file with its own **PDF metadata**. Here's what each part means.

## The document information dictionary

The classic PDF properties include:

- **Title:** often copied from the source document, sometimes an old internal name.
- **Author:** usually your name from Word or your computer.
- **Subject and Keywords:** descriptive fields.
- **Creator:** the program used to make the original document, such as a word processor or design app.
- **Producer:** the software that generated the PDF, which may include a version number.
- **CreationDate and ModDate:** precise timestamps.

## XMP metadata

Most modern PDFs also contain an XMP metadata stream. It repeats many of the fields above and can add more, such as document IDs and editing history. Removing only the classic properties can leave XMP behind. See [PDF XMP metadata](pdf-xmp-metadata.html).

## Incremental updates

When a PDF is edited and saved in some programs, the changes are added to the end of the file rather than rewriting it. Older versions of the content and metadata can remain inside the file. Tools that rewrite the whole PDF as a single version remove those leftovers.

## Other places information hides

- **Annotations and comments** with author names
- **Form field values**
- **Attachments** embedded in the PDF
- **Images** that keep their own metadata
- **Bookmarks** and hidden layers

Open a PDF's properties and you'll see three fields that often confuse people: **Author, Creator and Producer**.

## Author

The person who wrote the document, usually filled in automatically from your user account. It may be your full name, a shortened account name, or someone else's name if you started from their file.

## Creator

The application used to create the original document before it became a PDF, for example a word processor, spreadsheet, design app or browser. It shows what software you use and sometimes its version.

## Producer

The software that actually generated the PDF file. This can be a PDF printer driver, a library used by a website, or an export feature. It often includes version numbers.

## Why these fields matter

- They can identify you by name.
- They show which tools you use, which matters if you're presenting work as made a certain way.
- Software versions can hint at outdated, vulnerable programs.
- A "Producer" from an online converter shows you uploaded the document to that service.

=== pdf-redaction-vs-metadata-removal
title: PDF Redaction vs Metadata Removal: What's the Difference?
cat: PDF
kw: pdf redaction vs metadata, redact pdf properly, black box redaction mistake, remove hidden text pdf, pdf redaction
desc: Redaction and metadata removal are different. Learn why drawing black boxes over PDF text doesn't hide it, and how to redact and clean PDFs properly.
---
People often confuse **redaction** and **metadata removal**. Both protect information, but they protect different things.

## Metadata removal

Removes hidden data about the document: author, title, software, dates and XMP. It doesn't change any of the visible pages.

## Redaction

Permanently removes visible content from the pages: names, account numbers, addresses. Proper redaction deletes the underlying text and images, not just covers them.

## The black box mistake

A common and serious error is drawing black rectangles over text in a PDF. The box hides the text on screen, but the text is still in the file. Anyone can select it, copy it or remove the box. Highlighting text in black has the same problem.

## How to redact properly

- Use a real redaction tool that removes the content underneath, then apply the redactions.
- Or, for simple cases, edit the source document to remove the text, then export a new PDF.
- After redacting, check by trying to select and search for the removed text.

## Then remove metadata

Redaction tools don't always clear the document properties, and your source file may have added your name and software. After redacting, run the PDF through GetFileClean to remove the author, creator, producer, dates and XMP.

## Summary

- Visible sensitive content: **redact**.
- Hidden information about the file: **remove metadata**.
- Sharing sensitive PDFs: **do both**.

---
If a PDF has a **digital signature**, removing its metadata will make the signature invalid. Here's why, and what to do instead.

## Why signatures break

A digital signature protects the exact bytes of the document at the moment of signing. Any change to the signed content, including metadata, means the document no longer matches what was signed. PDF readers then warn that the document has been modified.

## The right order: clean first, then sign

1. Finish the document.
2. Remove metadata with GetFileClean.
3. Then apply the digital signature.

The signed file will contain the signer's certificate information, which is expected and needed to verify the signature.

## What if you've received a signed PDF?

Don't clean it if the signature needs to stay valid, for example contracts, official certificates or invoices that must be verified. Share it as it is.

## E-signature platforms

Documents signed through e-signature services often include signer names, emails and audit information. This is part of their legal value. Removing it may make the document less useful as evidence.

## How GetFileClean handles signed PDFs

GetFileClean detects digitally signed PDFs and shows a warning that the signature will no longer be valid after cleaning. You can then decide whether to keep the original.

=== pdf-xmp-metadata
title: PDF XMP Metadata: The Hidden Copy Most Tools Miss
cat: PDF
kw: pdf xmp metadata, remove xmp from pdf, xmp metadata stream, pdf metadata stream, adobe xmp pdf
desc: PDFs often store a second copy of their metadata in XMP. Learn what PDF XMP metadata contains and why removing only the document properties isn't enough.
---
Most people check PDF metadata in the **Document Properties** window. But modern PDFs usually store a second copy of that information in **XMP metadata**, which many basic tools don't touch.

## What is XMP in a PDF?

XMP is an XML-based metadata format. In a PDF it's stored as a separate data stream attached to the document. It can include:

- Title, author and description
- Creator tool and producer
- Creation, modification and metadata dates
- Document and instance IDs, which can link versions of the same document
- Editing history from some design applications

## Why it gets missed

If you edit the Author field in a basic tool, it may update the classic document properties but leave the XMP stream unchanged. A PDF can show a blank author in one viewer and the original name in another.

## Pages and images can have XMP too

XMP can be attached to individual pages and embedded objects, not just the whole document.

## How GetFileClean handles PDF XMP

GetFileClean removes the document-level XMP stream and any XMP or private app data attached to pages and objects, as well as the classic document information. Then it saves the PDF as a single clean version.

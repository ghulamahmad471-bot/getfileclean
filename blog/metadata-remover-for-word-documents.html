Metadata Remover for Word Documents, Excel and PowerPoint Files

GetFileClean TeamDocuments · 8 min read · Updated 2026-11-25

A good metadata remover for Word documents, Excel workbooks and PowerPoint presentations has two jobs. It must clear the file properties (author, last modified by, company, dates, template, custom fields), and it must leave the visible content exactly as it was. Some of the most revealing leftovers in Office files, such as comments, tracked changes and speaker notes, aren't metadata at all, so no property cleaner will touch them. This guide covers what each part of an Office file can reveal, which tool handles which part, and how to check the result yourself.

For click-by-click steps in a single app, see our guides for Word, Excel and PowerPoint. This article covers all three formats together and how to tell whether the job is actually done.

Why DOCX, XLSX and PPTX files can be cleaned the same way

Modern Office files (DOCX, XLSX, PPTX) are ZIP archives full of XML files. Rename a copy of report.docx to report.zip, open it, and you'll see folders like word/, docProps/ and _rels/. Excel uses xl/ and PowerPoint uses ppt/, but the metadata lives in the same place in all three:

  • docProps/core.xml: author (creator), last modified by, title, subject, keywords, description, revision number, created and modified dates.
  • docProps/app.xml: company, manager, the application and version that saved the file, template name, total editing time, and counts of pages, words or slides.
  • docProps/custom.xml: custom properties added by you, your company's document management system, or sensitivity labelling tools. These can include client names, matter or project numbers and internal IDs.
  • Media folders (word/media/, xl/media/, ppt/media/): every photo you inserted, often still carrying its own EXIF data, including the camera or phone model and sometimes GPS coordinates.

Because the layout is shared, a single metadata remover can handle all three formats, as long as it understands this layout and doesn't simply rename or re-compress the file.

What a property cleaner won't remove

These parts sit in the document content, not in docProps, so a metadata remover that only clears properties leaves them untouched:

  • Comments and their author names. Word and Excel store each reviewer's name with every comment. Modern comments can also record a separate list of people.
  • Tracked changes (revisions). Deleted text can stay in the file, and each change is tagged with an author and a time. This is often the most damaging leak; see why tracked changes and comments are a bigger risk.
  • Speaker notes and hidden slides in PowerPoint.
  • Hidden rows, columns and sheets in Excel, plus cell comments and notes, named ranges, and links to external workbooks whose file paths can show folder or server names.
  • Hidden text, headers, footers and watermarks in Word.
  • Content placed off the page or off the slide, and objects covered by other objects.

Handle these in the Office app itself, because deciding whether a comment or hidden sheet should go is a content decision only you can make.

Method 1: Document Inspector (Word, Excel and PowerPoint on Windows)

Microsoft's built-in tool is the most complete option for content leftovers. According to Microsoft's current help page, in Word you:

  1. Save a copy first with File > Save As. Microsoft warns that it isn't always possible to restore data the inspector removes, even with Undo.
  2. Go to File > Info > Check for Issues > Inspect Document.
  3. Leave the check boxes ticked and select Inspect.
  4. Select Remove All next to each category you want cleared, then Reinspect to confirm.
  5. Save the file.

In Word the categories are Comments, Revisions, Versions, and Annotations; Document Properties and Personal Information; Headers, Footers, and Watermarks; Hidden Text; Custom XML Data; and Invisible Content. Excel and PowerPoint use the same File > Info > Check for Issues > Inspect Document path, with app-specific checks for things like hidden rows and worksheets in Excel and presentation notes and off-slide content in PowerPoint. The exact list depends on your Office version.

Two limits Microsoft points out: the Hidden Text check only finds text formatted as hidden (white text on a white background isn't detected), and the Invisible Content check can't see objects hidden behind other objects. Our Inspect Document walkthrough goes through every category.

What Document Inspector doesn't do: it doesn't remove EXIF data from photos inside the document, and it works on one file at a time.

Method 2: Office for Mac

Office for Mac doesn't offer Document Inspector under File > Info. In recent versions of Word for Mac, a privacy option to remove personal information when saving appears under Tools > Protect Document (some versions show it under Review > Protect). Labels have moved between releases, so if you can't find it, search the Help menu for "personal information". Alternatively, open File > Properties and clear the Summary and Custom tabs by hand. Comments and tracked changes still have to be deleted or accepted separately on the Review tab.

How to check a cleaned Office file yourself

1. Look at the properties. In Office on Windows, open the file and go to File > Info, then check the Properties panel and Related People (Author, Last Modified By). In File Explorer, right-click the file, choose Properties > Details, and look at Authors, Last saved by and Company. On a Mac, use File > Properties in the Office app.

2. Look inside the ZIP. Copy the file, rename the copy's extension to .zip, and open docProps/core.xml and docProps/app.xml in a text editor. You should see no names, company or template. Also open the media folder and check that no images you meant to remove are still there.

3. Search for your name. Use a tool that searches inside the archive's XML, or unzip it and search the folder for your name, your company and your computer's username. If your name turns up in comments.xml, people.xml or the main document XML, it's in comments, revisions or the text itself.

4. Check the preview image. Some files include docProps/thumbnail.jpeg, a small picture of the first page or slide saved when the "save preview picture" or thumbnail option is turned on. If the first page shows something sensitive, turn that option off and save again.

FAQ

Does a metadata remover for Word documents change the formatting?

It shouldn't. The properties are stored in separate files inside the document package, so clearing them doesn't change the text, styles, tables or layout. If a document looks different after cleaning, the tool rewrote more than it should have.

Does Document Inspector remove the metadata from images inside a Word file?

No. It removes document properties and content such as comments, but photos inside the document keep their own EXIF data. A metadata cleaner that processes embedded images, or cleaning the photos before you insert them, solves this.

Will removing metadata delete my comments and tracked changes?

A property-only metadata cleaner won't delete them. That's why you should accept or reject all changes and delete the comments in Word, Excel or PowerPoint before sharing a final version. Document Inspector can remove them, but only on a copy you've checked.

Is it safe to clean Office files online?

That depends on whether the tool uploads them. Contracts, CVs and financial workbooks are exactly the files you don't want on a stranger's server. Use a tool that processes files locally in your browser, or the built-in options in Office.

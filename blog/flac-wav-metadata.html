How to Remove Metadata from FLAC and WAV Audio Files

GetFileClean TeamVideo & Audio · 2 min read · Updated 2026-11-25

High-quality audio formats carry their own kinds of metadata. Here's how to remove metadata from FLAC and WAV files.

FLAC metadata

FLAC files start with metadata blocks:

  • Vorbis comments: tags like ARTIST, TITLE, ALBUM, DATE and ENCODER, plus any custom fields.
  • Picture blocks: embedded cover art.
  • Application blocks: data from specific software.

The stream info and seek table blocks are technical and needed for playback.

WAV metadata

WAV files are made of chunks. Metadata chunks include:

  • LIST/INFO: artist, title, comments, software and dates.
  • bext (Broadcast Wave): originator, description, origination date and time, used by professional recorders.
  • iXML: detailed production data from field recorders, such as scene, take and notes.
  • id3: some software adds ID3 tags to WAV files.
  • XMP: from Adobe audio software.

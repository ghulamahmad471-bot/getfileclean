How to Remove EXIF Data on Windows 10 and 11

GetFileClean TeamPhoto Privacy · 2 min read · Updated 2026-11-25

Windows has a built-in way to remove EXIF data from photos. Here's how to remove EXIF data on Windows, plus what the built-in tool misses.

Use "Remove Properties and Personal Information"

  1. In File Explorer, select one or more photos.
  2. Right-click and choose Properties.
  3. Open the Details tab.
  4. Click Remove Properties and Personal Information at the bottom.
  5. Choose Create a copy with all possible properties removed, then click OK.

Windows creates copies with "Copy" in the name. Alternatively, choose Remove the following properties from this file and tick the fields you want to delete.

Limitations of the Windows method

  • It doesn't always remove everything. Some XMP data and app-specific blocks can remain.
  • It works best on JPG. Support for PNG, WebP and other formats is limited.
  • It doesn't show you what was found before removing it.
  • It handles PDFs and videos poorly or not at all.

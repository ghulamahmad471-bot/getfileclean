PDF XMP Metadata: The Hidden Copy Most Tools Miss

PDF · 2 min read · Updated 2026-11-25

Most people check PDF metadata in the Document Properties window. But modern PDFs usually store a second copy of that information in XMP metadata, which many basic tools don't touch.

What is XMP in a PDF?

XMP is an XML-based metadata format. In a PDF it's stored as a separate data stream attached to the document. It can include:

  • Title, author and description
  • Creator tool and producer
  • Creation, modification and metadata dates
  • Document and instance IDs, which can link versions of the same document
  • Editing history from some design applications

Why it gets missed

If you edit the Author field in a basic tool, it may update the classic document properties but leave the XMP stream unchanged. A PDF can show a blank author in one viewer and the original name in another.

Pages and images can have XMP too

XMP can be attached to individual pages and embedded objects, not just the whole document.

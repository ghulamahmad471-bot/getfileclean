Metadata and GDPR: Is Metadata Personal Data?

Privacy & Security · 2 min read · Updated 2026-11-25

Under privacy laws like the EU's GDPR, personal data means information relating to an identified or identifiable person. Much file metadata fits that description.

Metadata that can be personal data

  • Author and editor names in documents
  • GPS coordinates in photos taken at someone's home
  • Device serial numbers that can be linked to a person
  • Timestamps combined with other details
  • Names in comments and tracked changes

Data minimisation

GDPR includes the principle of data minimisation: personal data should be adequate, relevant and limited to what's necessary. Sending documents full of names and location data that the recipient doesn't need sits awkwardly with that principle.

Practical steps

  1. Remove metadata from files shared outside the organisation where it isn't needed.
  2. Clean images before publishing them on websites.
  3. Include metadata in your privacy training.
  4. Prefer tools that don't upload files to third parties, since uploading personal data to another service can create further obligations.

When you must keep metadata

Some legal, regulatory and records-management duties require preserving original files with metadata. Keep originals where required and clean only the copies you share.

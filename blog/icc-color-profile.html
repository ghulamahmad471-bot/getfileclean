Should You Remove the ICC Colour Profile When Cleaning Metadata?

Technical · 2 min read · Updated 2026-11-25

When you remove metadata, should the ICC colour profile go too? In most cases, no.

What is an ICC profile?

An ICC profile describes the colour space of an image, such as sRGB, Display P3 or Adobe RGB. It tells screens and printers how to interpret the colour values stored in the pixels.

What happens if you remove it

Without a profile, software usually assumes sRGB. If the image was in a wider colour space, such as Display P3 from many modern phones or Adobe RGB from a camera, colours can look duller or shifted.

Is a colour profile private?

Generally, no. A profile describes colours, not you. Standard profiles like sRGB or Display P3 are shared by millions of images. Custom profiles from calibrated monitors could contain a profile name, but that's uncommon in shared images.

Converting instead

If you need to remove a wide-gamut profile for compatibility, convert the image to sRGB in an image editor first. That changes the pixel values so colours stay correct without the profile.

PDF Redaction vs Metadata Removal: What's the Difference?

PDF · 2 min read · Updated 2026-11-25

People often confuse redaction and metadata removal. Both protect information, but they protect different things.

Metadata removal

Removes hidden data about the document: author, title, software, dates and XMP. It doesn't change any of the visible pages.

Redaction

Permanently removes visible content from the pages: names, account numbers, addresses. Proper redaction deletes the underlying text and images, not just covers them.

The black box mistake

A common and serious error is drawing black rectangles over text in a PDF. The box hides the text on screen, but the text is still in the file. Anyone can select it, copy it or remove the box. Highlighting text in black has the same problem.

How to redact properly

  • Use a real redaction tool that removes the content underneath, then apply the redactions.
  • Or, for simple cases, edit the source document to remove the text, then export a new PDF.
  • After redacting, check by trying to select and search for the removed text.

Then remove metadata

Redaction tools don't always clear the document properties, and your source file may have added your name and software. After redacting, run the PDF through GetFileClean to remove the author, creator, producer, dates and XMP.

Summary

  • Visible sensitive content: redact.
  • Hidden information about the file: remove metadata.
  • Sharing sensitive PDFs: do both.

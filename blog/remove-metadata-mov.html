How to Remove Metadata from MOV Files (QuickTime Video)

GetFileClean TeamVideo & Audio · 2 min read · Updated 2026-11-25

MOV is Apple's QuickTime video format, used by iPhones and many cameras and editing apps. Here's how to remove metadata from MOV files.

What's inside MOV metadata?

MOV and MP4 share the same basic structure. MOV files commonly store:

  • Location in a standard text format with latitude and longitude
  • Make, model and software of the recording device
  • Creation dates for the movie and each track
  • Titles, descriptions and keywords added by editing software

GetFileClean finds and wipes the metadata sections inside MOV files and clears creation dates, without re-encoding. Your video plays exactly as before and the file size doesn't change.

Should you convert MOV to MP4 instead?

Converting changes the container and may re-encode the video. It can also add new metadata from the converter. If you only need to remove metadata, clean the MOV directly.

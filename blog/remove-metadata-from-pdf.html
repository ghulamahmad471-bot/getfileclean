How to Remove Metadata from PDF Files (Free, No Upload)

PDF · 2 min read · Updated 2026-11-25

PDFs are the standard format for sharing finished documents, and almost every PDF contains metadata. Here's how to remove metadata from PDF files safely.

What metadata is in a PDF?

  • Document information: Title, Author, Subject, Keywords, Creator (the app that made the original document), Producer (the software that made the PDF), Creation Date and Modification Date.
  • XMP metadata: a second, more detailed copy of these fields, sometimes with extra history.
  • Private app data: some design programs store their own data inside PDFs.

Important exceptions

  • Signed PDFs: any change invalidates a digital signature. See signed PDFs and metadata.
  • Password-protected PDFs: remove the password with the owner's permission before cleaning.
  • Redaction: metadata removal isn't redaction. Black boxes drawn over text don't remove the text. See redaction vs metadata removal.

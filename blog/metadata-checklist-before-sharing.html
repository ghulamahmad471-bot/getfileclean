Metadata Checklist: 10 Things to Check Before Sharing a File

Metadata Basics · 2 min read · Updated 2026-11-25

Use this metadata checklist before sharing files with anyone outside your circle.

For every file

  1. Is it the final version? Not a draft with old content.
  2. Are file and folder names neutral? No client names, personal names or internal labels.
  3. Has metadata been removed? Run it through GetFileClean and check the report.

For documents

  1. Tracked changes accepted or rejected? And Track Changes turned off.
  2. Comments deleted? Including resolved comments.
  3. Hidden text, rows, columns and sheets checked? See hidden data in spreadsheets.
  4. Redactions done properly? No black boxes over live text. See redaction vs metadata removal.

For photos and videos

  1. Location removed? The GetFileClean report shows GPS in red if it was found.
  2. Visible clues checked? House numbers, number plates, documents, screens and reflections.

For everything

  1. Is the original stored safely? Keep it privately if you need it, and share only the clean copy.

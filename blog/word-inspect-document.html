Word Inspect Document: Remove Hidden Data Step by Step

Documents · 2 min read · Updated 2026-11-25

Microsoft Word includes a Document Inspector that finds hidden data and personal information. Here's how to use Inspect Document properly.

How to run Inspect Document

  1. Open the document and save a copy first, because some removals can't be undone.
  2. Click File > Info.
  3. Click Check for Issues > Inspect Document.
  4. If prompted, save your changes.
  5. Choose the content types to check and click Inspect.
  6. Review the results and click Remove All for each item you want to remove.
  7. Save the document.

What the Document Inspector checks

  • Comments, revisions and versions
  • Document properties and personal information, such as author, company and dates
  • Task pane add-ins and embedded documents
  • Collapsed headings
  • Custom XML data
  • Headers, footers and watermarks
  • Invisible content and hidden text

Be careful with headers and watermarks

Removing headers and footers deletes them completely, including page numbers and logos you may want to keep. Only remove what you intend to.

What it doesn't do

The Inspector doesn't clean metadata inside images embedded in the document. A photo pasted into a report can still carry its GPS location. It also requires Word, one file at a time.

PDF Metadata Explained: Every Hidden Field and What It Reveals

GetFileClean TeamPDF · 2 min read · Updated 2026-11-25

A PDF looks like a finished page, but inside it's a structured file with its own PDF metadata. Here's what each part means.

The document information dictionary

The classic PDF properties include:

  • Title: often copied from the source document, sometimes an old internal name.
  • Author: usually your name from Word or your computer.
  • Subject and Keywords: descriptive fields.
  • Creator: the program used to make the original document, such as a word processor or design app.
  • Producer: the software that generated the PDF, which may include a version number.
  • CreationDate and ModDate: precise timestamps.

XMP metadata

Most modern PDFs also contain an XMP metadata stream. It repeats many of the fields above and can add more, such as document IDs and editing history. Removing only the classic properties can leave XMP behind. See PDF XMP metadata.

Incremental updates

When a PDF is edited and saved in some programs, the changes are added to the end of the file rather than rewriting it. Older versions of the content and metadata can remain inside the file. Tools that rewrite the whole PDF as a single version remove those leftovers.

Other places information hides

  • Annotations and comments with author names
  • Form field values
  • Attachments embedded in the PDF
  • Images that keep their own metadata
  • Bookmarks and hidden layers

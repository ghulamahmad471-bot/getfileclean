How to Remove PDF Metadata on a Mac

PDF · 2 min read · Updated 2026-11-25

macOS makes PDFs easy to create and view, but removing their metadata takes a little more work. Here's how to remove PDF metadata on a Mac.

View PDF metadata in Preview

  1. Open the PDF in Preview.
  2. Choose Tools > Show Inspector.
  3. The info tab shows the title, author, subject, keywords, creator, producer and dates.

Can Preview remove PDF metadata?

Preview shows metadata but offers very limited editing of it. Saving or exporting a PDF from Preview may also set itself as the producer. It isn't a reliable way to strip everything.

Print to PDF isn't a clean fix

Using Print > Save as PDF creates a new PDF, but the new file gets its own metadata, often including the title and the producer.
